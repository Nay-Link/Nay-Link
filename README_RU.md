### Nebula K8s Lab

- **Цель:** показать развёртывание Kubernetes в учебной среде.
- **Пример структуры:** 3 control-plane + 3 worker.
- **Что добавим позже:** inventory, playbook, вывод проверок, разбор ошибок.

### Signal Observatory

- **Цель:** проследить путь события приложения до графика и оповещения.
- **Пример потока:** приложение → метрики/логи → Prometheus/Loki → Grafana.
- **Что добавим позже:** дашборды, правила алертов, скриншоты.

### Pipeline Garage

- **Цель:** показать понятную последовательность CI/CD.
- **Пример этапов:** lint → test → build → scan → publish.
- **Что добавим позже:** настоящие pipeline YAML, логи, значки статуса сборки.

### Infra Notebook

- **Цель:** собрать понятные воспроизводимые заметки о Linux и сетях (пример).
- **Что добавим позже:** конфиги, диагностические команды, скриншоты.

## 📝 Как документирую проекты

1. **Контекст:** задача и планируемая архитектура.
2. **Развёртывание:** последовательность действий и настройки.
3. **Проверка:** что проверялось и какие результаты получились.
4. **Troubleshooting:** ошибки, диагностика, исправления.
